# Event Recap: AWS Cloud Mastery Series #3 – Security Architecture

## Core Objectives
- Identity Architecture: Establish a foundational understanding of AWS security, distinguishing standard IAM from IAM Identity Center (formerly SSO).
- Access Governance: Demonstrate centralized access control and operational efficiency via Single Sign-On (SSO).
- Advanced Controls: Explain and apply governance guardrails using Service Control Policies (SCPs) and Permission Boundaries in multi-account environments.
- Operational Security: Provide hands-on experience with the security lifecycle—credential rotation, MFA enforcement, and threat detection.

## Instructors
- Van Hoang Kha – AWS Community Builder
- Cloud Club Captains (HCMUTE, HUFLIT & PTIT)
- Dinh Le Hoang Anh & Huynh Hoang Long – Cloud Engineer Trainees (First Cloud AI Journey)

## Session Highlights
### Identity Strategy
- When to deploy IAM vs. IAM Identity Center, emphasizing scalability, centralization, and least-privilege at scale.

### Governance Deep Dive
- How SCPs and Permission Boundaries complement each other as guardrails to enforce org-wide policies and delegated controls.

### Live Configuration
- Guided demo onboarding users to IAM Identity Center and configuring AWS CLI access via SSO profiles.

### Holistic Security Lifecycle
- End-to-end coverage of six domains: Identity, Detection, Infrastructure Protection, Data Security, Incident Response, and App Security.

### Tooling Implementation
- Practical setup of IAM Access Analyzer and use of GuardDuty, CloudTrail, and Security Hub for continuous detection and visibility.

## Strategic Takeaways
- Identity First: Identity is the new perimeter; IAM Identity Center is essential for managing access at scale.
- Defense in Depth: Combine preventative controls (SCPs, boundaries) with detective controls (CloudTrail, Security Hub).
- Automation: Prefer automated remediation and continuous monitoring over periodic manual checks.
- DevSecOps: Integrate secret management, policy checks, and runtime protections into CI/CD pipelines.

## Event Assessment
The workshop moved beyond theory to practical implementation. By connecting identity, governance, and detection with live demos, participants saw how abstract policies translate into concrete CLI/console workflows and how security domains interlock across the AWS ecosystem.
