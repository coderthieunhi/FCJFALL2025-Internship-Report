# Event Recap: Leveraging AWS for Modern Data Science

## Primary Goals
- Workflow Familiarization: Acquaint participants with modern data science lifecycles on AWS Cloud.
- Infrastructure Insights: Show how cloud services support data processing, model training, deployment, and scaling.
- Applied Learning: Run a hands-on ML project with real datasets to reinforce concepts.

## Featured Speakers
- Van Hoang Kha - AWS Community Builder
- Bach Doan Vuong - Cloud DevOps Engineer, AWS Community Builder

## Session Highlights
- Expert-led sessions on building data pipelines and deploying ML models on cloud infrastructure.
- Overview of AWS Generative AI services and practical real-world applications.
- End-to-end walkthrough: building a Sentiment Analysis model using AWS-powered ML tools.

## Key Takeaways
- Cloud-based data science requires understanding pipelines, infrastructure, and deployment workflows—not just algorithms.
- The cloud accelerates experimentation and scaling; cost management remains essential.
- Hands-on demos make ML more accessible than abstract theory alone.
- Exposure to industry practices helps align academic knowledge with real engineering expectations.
