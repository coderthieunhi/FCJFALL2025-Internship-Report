# Tổng kết sự kiện: Ứng dụng AWS cho Khoa học Dữ liệu hiện đại

## Mục tiêu chính
- Làm quen quy trình vòng đời khoa học dữ liệu hiện đại trên AWS Cloud.
- Minh họa cách dịch vụ đám mây hỗ trợ xử lý dữ liệu, huấn luyện mô hình, triển khai và mở rộng.
- Học qua thực hành: xây dựng dự án ML với bộ dữ liệu thực tế để củng cố kiến thức.

## Diễn giả
- Văn Hoàng Kha - AWS Community Builder
- Bách Đoàn Vương - Cloud DevOps Engineer, AWS Community Builder

## Điểm nhấn
- Chuyên gia chia sẻ về xây dựng pipeline dữ liệu và triển khai mô hình ML trên hạ tầng cloud.
- Tổng quan dịch vụ Generative AI của AWS và các ứng dụng thực tiễn.
- Hướng dẫn end-to-end: xây dựng mô hình phân tích cảm xúc (Sentiment Analysis) bằng các công cụ ML trên AWS.

## Bài học rút ra
- Khoa học dữ liệu trên cloud đòi hỏi hiểu pipeline, hạ tầng và quy trình triển khai — không chỉ thuật toán.
- Cloud tăng tốc thử nghiệm và mở rộng; quản lý chi phí luôn là yếu tố then chốt.
- Demo thực hành giúp ML dễ tiếp cận hơn so với lý thuyết thuần túy.
- Tiếp xúc thực tiễn doanh nghiệp giúp thu hẹp khoảng cách giữa kiến thức học đường và kỳ vọng kỹ sư thực tế.
