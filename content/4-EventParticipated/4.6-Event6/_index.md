# Event Recap: Cloudthinker - Building Agentic AI & Context Optimization with Amazon Bedrock

## Core Objectives
- From Prototype to Production: Guide attendees from POC to production-grade agents using Bedrock AgentCore.
- Cloud Automation: Show how AI agents autonomously perform cost optimization, security hardening, and resource ops across clouds.
- Applied Architecture: Bridge high-level design with hands-on implementation of AI-driven workflows.
- Operational Efficiency: Demonstrate how Agentic AI streamlines operations and reduces manual engineering overhead.

## Speakers
- Nguyen Gia Hung – Head of Solutions Architect, AWS
- Kien Nguyen – Solutions Architect, AWS
- Viet Pham – Founder & CEO, Diaflow
- Thang Ton – Co-founder & COO
- Henry Bui – Head of Engineering, CloudThinker
- Kha Van – AWS Community Builder

## Session Highlights
- Platform Architecture: Deep dive into CloudThinker’s agent platform for modern cloud operations.
- Orchestration Logic: Combining Amazon Bedrock with agentic orchestration to build autonomous workflows.
- Live Use Cases: Agents handling cost optimization, resource monitoring, security audits, and cross-cloud tasks.
- CloudThinker Hack: Hands-on segment to build and test agent-driven tasks.
- Networking: Lunch session for discussions with the CloudThinker team and peers.

## Key Takeaways
- Shift in Operations: Properly orchestrated agents remove boilerplate ops, freeing engineers for higher-value architecture.
- Accessible Automation: Tools like CloudThinker make multi-cloud optimization attainable without heavy internal tooling.
- Hybrid Approach: Effective cloud management blends AI, automation, and human oversight for cost, performance, and security.
- Practicality Over Hype: Hands-on trials reveal real trade-offs and design choices behind “automate everything.”

## Event Experience
The event demystified agentic AI with clear end-to-end narratives and working demos. Presenters showed how orchestration and cloud services converge to deliver scalable, secure operations. Live showcases of cost analysis and security findings highlighted tasks that typically consume significant engineer hours, reframing them as automated, auditable workflows.
